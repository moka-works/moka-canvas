## 介绍

摩卡画布（Moka Canvas）是一款本地优先的 AI 创作工具：项目、素材与密钥都保存在你自己的机器上，没有账号，数据不上传。它把创作放在一块可以无限延伸的画布上：文本、图片、音频、视频都是一张张卡片，用连线表达内容的传递，一次创作就是把这条链路摆出来、跑起来。

摩卡画布本身不提供 AI 能力。你把自己常用的模型服务接进来——写好接口地址、模型名称与密钥——画布上的生成就交给它们完成。用哪家的模型、同时用几个，完全由你决定；清单里没有的模型，也可以通过“转换器”加进来。

生成的东西都会留在项目里：图片、声音、视频自动归档进素材架，可以继续被画布引用，也可以拿去剪辑模块剪成成片；故事模块则把“讲一个故事”拆成五个步骤，从一段创意一路走到可以导出的影片。

详细使用文档: [https://moka-canvas.art](https://moka-canvas.art)

**如果摩卡画布对你有所帮助，请为此代码库点一个 Star :star: 支持如使用中遇到问题，欢迎提 [Issue](https://github.com/moka-works/moka-canvas/issues/new) 反馈**

## 主要功能

- **无限画布**：双击空白处添加节点，从卡片边上拖出连线建立引用；支持分组、对齐、分布，滚轮缩放（5%–500%），左下角的小地图负责导航。
- **可预期的生成**：选中节点就出现生成面板，写提示词、挑模型、调参数；运行之前先点“预览”，看到真正会提交给模型的内容；运行失败不会覆盖卡片上已有的结果。
- **助理对话**：在画布边上和 AI 聊着改——会话围绕你选中的卡片展开，回答可以变成新卡片、写入所选文本，或者直接生成一张图、一段视频、一段音频。
- **图片工具**：裁剪、分割、重采样、透视是本地运算，不花一分钱也不依赖模型；重绘（涂抹遮罩）与描述（把图片读回成提示词）则调用模型，产物都记得自己从哪来。
- **素材架**：项目里的全部文件按文本、图像、音频、视频分列，可搜索、可备注、可收藏；每个文件都能查到自己被哪些画布、剪辑与故事引用。
- **剪辑模块**：多轨时间线、七种转场、字幕编辑与 SRT 导入导出，还有自动字幕；导出 MP4 用本机 ffmpeg 精确渲染。
- **故事模块**：创意 → 大纲 → 剧情元素 → 分镜脚本 → 合成视频，每一步都是一批可以阅读、修改、确认的 AI 提问，最后拼出成片交给剪辑模块精修。
- **项目可以随时带走**：项目就是一个普通文件夹，拷走即迁移；也可以导出成一个 `.mokapkg.zip` 项目包，在另一台机器上导入。

## 快速开始

### 1. 选择一种运行方式

- **桌面应用**（macOS、Windows、Linux）：装好即用，适合个人创作，密钥由系统钥匙链保护；
- **自托管**：把程序跑在一台自己的机器上，用浏览器访问，适合没有桌面环境的机器或部署给内网；
- **从源码运行**：开发者路线，需要 Node.js 22+ 与 Rust 工具链，细节见[构建指南](BUILD.md)。

### 2. 新建一个项目

启动后先在启动器里点 **新建项目**：填写项目名称、选一个文件夹即可。项目就是一个普通文件夹，画布文档与素材都在里面。新建的项目会直接进入**故事模块**；想从画布开始，用左上角的项目菜单切到画布。从启动器的**最近项目**列表也能直接进入四个模块中的任意一个。

### 3. 接上一个模型

打开 **设置 → 模型**，先选分类页签（文本、图像、语音合成、音乐生成、视频、语音识别），再点新建，填写模型的显示名称和其他具体信息。保存后，在同类卡片上选定相应模型即可。

密钥只写入、不回显：界面上永远只显示掩码，留空保存就是保持原值。

### 4. 生成第一张图

1. 双击画布空白处，添加一个 **文本** 节点，双击卡片写下描述，例如“暮色四合，一盏灯笼漂过寂静的湖面”；
2. 右键点击文本卡片，选择 **用这些文字生成图片**——画布上会落下一张图片节点并自动接好连线；
3. 确认提示词与模型，点 **运行**；
4. 完成后结果直接落在卡片上，同时归档为项目素材，随时可以再用。

### 5. 认识四个模块

- **画布**：节点、连线与生成，工作的地方；
- **故事**：一次讲述的五个步骤，从创意到成片；
- **剪辑**：时间线、转场与字幕，把素材剪成片子；
- **素材**：项目全部文件一处读、一处管。

左上角的项目菜单在四个模块之间随时互相切换。界面有简体中文与 English 两套，默认跟随系统，在 **设置 → 系统 → 语言** 里可以固定。

## 数据保存在哪里

- **项目内容**（画布文档、素材、故事与运行记录）都在你选择的项目文件夹里：把整个文件夹拷走，项目就完整地跟着走；
- **应用状态**（模型配置、API 密钥、偏好设置、最近项目列表）保存在系统的应用数据目录（macOS 为 `~/Library/Application Support/MokaCanvas/`，Windows 为 `%APPDATA%\MokaCanvas\`），不随项目走；密钥加密保存，只写不回显；
- 没有账号、没有云同步、不上传遥测；唯一的联网请求就是你配置的模型端点。

视频导出与自动字幕需要机器上装有 ffmpeg 5.0 及以上（一个开源的视频处理工具，需要带 libass 支持的完整版本，安装方法见[构建指南](BUILD.md)）；没有它，其余功能一切照常，只有这两处会提示不可用。

## 构建与打包

从源码构建需要 Node.js 22+、npm 与 Rust 工具链（桌面打包还需要各平台的原生依赖）。常用命令：

```sh
make install
make web-serve   # 构建并启动本地服务器，浏览器打开 http://127.0.0.1:8080
make tauri-dev   # 运行桌面壳
```

完整的构建、打包与签名说明见[构建指南](BUILD.md)（英文版为 [BUILD_EN.md](BUILD_EN.md)）。技术栈：Rust 本地服务器（Axum）· React 19 + LeaferJS 前端 · Tauri 2 桌面壳。
